# 短剧悬疑感剧本与视频生成

## Core Methodology

### 1. 冲突驱动的结构逻辑 (Conflict-Driven Structure)
将60秒视频划分为四个关键象限，确保每一秒都在推进悬疑感：
- **压迫开场 (0-10s)**：通过静态构图与动态运镜（如推镜头）对比，建立人物关系的紧绷感。
- **言语交锋 (10-25s)**：利用简短而有力的台词，迅速建立人物对立立场。
- **动作拐点 (25-40s)**：设计物理冲突（如拔剑、扣腕、递交证物），作为情感爆发的载体。
- **信息差反转 (40-60s)**：抛出颠覆性的第三方信息，留下开放式钩子（Hook）。

### 2. 视觉一致性框架 (Visual Identity Framework)
在多镜头生成中保持核心视觉要素的恒定：
- **角色形象固定**：严格锁定人物的五官特征、特定饰品（如凤冠、玉佩）与服装主色调。
- **光影氛围编码**：使用"冷暖对比光"暗示冲突（如红烛火光与寒冷背景色调的冲撞）。

## Workflow

### 1. Preparation Stage
- **角色画像提取**：基于参考图提取发型、服饰细节、妆造风格及性格眼神（冷淡/狠戾）。
- **环境资产核查**：确定核心场景（如王府寝殿）的标志性道具（帷幔、红烛、玉佩）。
- **语言风格校准**：设定台词为中文古风或现代干练风，确保持续的张力。

### 2. Initial Design Stage
- **分段提示词生成**：[场景描述] + [动作/表情细节] + [光影氛围] + [景别/运镜]。
- **首镜校准**：先生成角色特写，确保其符合 [@image] 中的形象设定，作为后续生成的视觉基准。

### 3. Iteration Stage
- **一致性审计**：检查跨镜头中角色的五官连贯性及关键道具（如匕首、玉佩）的一致性。
- **节奏优化**：根据台词长度调整画面时长，确保声画同步。若氛围不足，增加细节描写（如眼神颤动、烛火闪烁）。

## Key Constraints & Standards
- **构图标准**：必须严格遵循 9:16 写实电影构图，确保主体人物位于垂直黄金分割线。
- **对白规则**：中文对白必须精炼，单句字数不宜过多，且必须体现人物当下的情感状态。
- **视觉禁令**：禁止出现角色瞬移或背景风格突变，严禁在同一场戏中更改光影主色调。
- **反转要求**：剧本必须在35秒至50秒区间内出现核心真相反转。
